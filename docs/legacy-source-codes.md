# Source codes in the earlier checklist

The earlier European checklist (in
[gaplist-data](https://github.com/bge-barcoding/gaplist-data)) records, for
each species, which sources listed it. The pipeline keeps these codes as the
evidence detail for each species, so they show up in the results.

Most codes are not documented in gaplist-data. **If you know what a code
stands for, please fill it in below.**

| Code | Species names | Meaning |
| --- | ---: | --- |

| BOLD | 51,505 | Barcode of Life Data System (BOLD) |
| WORMS | 18,377 | World Register of Marine Species (WoRMS) |
| SyDip | 18,182 | Systema Dipterorum (probably) |
| LF | 10,808 | *unknown* |
