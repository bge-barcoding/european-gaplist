# Earlier European checklist, by hand (usually not needed)

Normally section 2a of the notebook downloads the earlier checklist from
GitHub by itself, and you can leave this folder empty.

Only if that download does not work: get these two files from the `data`
folder of https://github.com/bge-barcoding/gaplist-data (at the version named
under `legacy: commit` in `config/sources.yaml`) and put them here:

- `Gap_list_all_updated.csv`
- `all_specs_and_syn.csv`

While both files are here, they are always used instead of the download.
